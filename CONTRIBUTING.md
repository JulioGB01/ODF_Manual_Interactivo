# Guía de contribución

Gracias por ayudar a mejorar esta referencia técnica.

## Seguridad y confidencialidad

No publiques planos reales, diagramas operacionales, datos de subestaciones, direcciones IP, nombres de clientes, fotografías sensibles, credenciales ni información de seguridad física. El repositorio debe contener solo ejemplos genéricos y contenido apto para divulgación pública.

## Pull requests

Explica el cambio, su fuente o criterio técnico y el efecto esperado en la documentación. Mantén el alcance educativo: el manual no reemplaza especificaciones, normas aplicables ni la revisión de un profesional competente.

Prueba el sitio en un navegador moderno y actualiza el README si cambia su alcance público.
